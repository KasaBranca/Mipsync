# UI fonts

Bundled **Inter** (from [Google Fonts](https://fonts.google.com/specimen/Inter)) for the editor UI.

| File | Weight |
|------|--------|
| `Inter-Regular.ttf` | 400 |
| `Inter-Medium.ttf` | 500 |
| `Inter-SemiBold.ttf` | 600 (optional; not loaded by default) |

License: see `LICENSE.txt` (SIL Open Font License 1.1).

To refresh fonts, download the family from Google Fonts and replace the `.ttf` files here, keeping the same filenames.
