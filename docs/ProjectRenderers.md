# ゲームごとのレンダラー

プロジェクトをこのバージョンのEditorで開くと、新規・既存を問わず以下のソースが自動で作成されます。

| 場所 | 編集できるもの | 反映方法 |
| --- | --- | --- |
| `renderer/pc/mesh.vert`、`skinned.vert`、`mesh.frag` | メッシュの頂点処理、スキニング、色・テクスチャ・ライティング | 保存後、約1秒でEditorへ反映 |
| `renderer/pc/screen.vert`、`screen.frag`、`skybox.frag` | 最終画面の処理、スカイボックス | 保存後、約1秒でEditorへ反映 |
| `renderer/pc/outline-mask.*`、`outline-compose.*` | 選択アウトライン | 保存後、約1秒でEditorへ反映 |
| `renderer/ps1/runtime/` | PS1の描画処理と関連するC・ヘッダーファイル | PS1の再ビルド、またはPlay |

PCはGLSL 330の描画ステージを差し替えます。エンジンが渡す入力を使う場合は、標準ソースのattribute location・uniform名を維持してください。コンパイル・リンクに失敗するとログへエラーを出し、直前に動作していた描画を維持します。PCプレイヤーにも編集したGLSLが暗号化パッケージ内で同梱されます。

PS1は`render.c` / `render.h`を起点に、クリッピング、プリミティブ生成、描画順、GPUへの転送などを変更できます。依存関係も編集できるよう、ランタイム全体を配置します。追加した`.c` / `.s` / `.S`もビルド対象になります。標準の`main.c`と生成されたシーンデータから呼ばれるインターフェースは維持してください。旧インタープリターの`vm.c`はnative AOTビルドの対象外です。

ゲーム側のソースを各シーンのビルドへ適用するため、複数シーンのゲームにも同じ変更が反映されます。出力先の`Builds/.../ps1_src/`は再生成されるので、編集は`renderer/ps1/runtime/`で行ってください。SDKコンパイルに失敗した場合、カスタムランタイムを無視して標準バイナリを成功扱いで実行することはありません。

アップデート後もプロジェクトを開くたびに同期します。未編集の標準ソースは更新し、編集済みファイルは保持します。比較・手動マージ用の現バージョンの標準ソースは`.nostalty/renderer-defaults/`に置かれます。この比較情報を含めてプロジェクトを移動すると、移動先でも未編集ソースを自動更新できます。以前から同名ファイルがあり比較情報がない場合は、そのファイルをユーザーの編集内容として保持します。

CLI用の`.agents/skills/mipsync-cli/`はEditorの同梱版へ毎回同期し、旧バージョンで廃止された参照ファイルも削除します。個別の指示は`AGENTS.md`のMipsync管理ブロック外に記述してください。管理ブロック外の内容は維持されます。
