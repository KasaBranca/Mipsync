## Mipsync 2026.8.26

Binary-only release for Windows x64. Target PS1 hardware with native engine & toolchain tools.

### Highlights (v2026.8.26)

- **PS1 Runtime & Animation Export**:
  - Export transform animations directly to the PS1 runtime format.
  - Enhanced PS1 Mips runtime compatibility validation.
  - Synchronized animation window with active animator component and selection.
  - Animation timeline improvements: keyframe copy & paste, refined timeline transport, ranges, and key editing.
- **Mipsync Hub Overhaul**:
  - Liquid glass UI redesign and modernized layout.
  - Normalized installed editor version listings and streamlined release feeds.
  - Added warning prompts before launching projects in outdated editor versions.
  - Project creation remembers the last chosen location.
  - Improved self-updater workflows.
- **Tooling & IDE**:
  - Bundled Mips# VS Code / Cursor extension and language server integration.
  - Bundled PCSX-Redux runtime, OpenBIOS, and PSn00bSDK project templates.

### Assets

- MipsyncEngine_Windows_x64.zip — Editor executable, PS1 runtime, templates, fonts/icons, and Mips# IDE tools.
- MipsyncHub_Windows_x64.zip — Mipsync Hub launcher and updater binaries.
- manifest.json — Update and release feed metadata.
