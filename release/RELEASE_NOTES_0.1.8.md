## Mipsync 0.1.8

Binary-only release (Windows x64).

### Highlights
- **Build** menu: Build Settings, Build Player (Unity-style `Product_Data` output)
- Mips# v0.4: scene load, save/load, physics callbacks, `Scene.LoadBuildIndex`
- Standalone player: `--play` and auto-detected `*_Data/boot.json`
